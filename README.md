## 🛍️ Customer Shopping Behavior Analysis

#### 📌 Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, product performance, and business insights. 

The analysis helps businesses understand customer behavior and make data-driven decisions to improve sales and customer satisfaction. 

#### 🎯 Project Objectives

* Analyze customer purchasing patterns.
* Identify popular product categories.
* Understand customer segmentation.
* Analyze subscription and discount usage.
* Generate meaningful business insights.
* Build an interactive Power BI dashboard.

#### 🛠️ Technologies Used

* **Python** – Data cleaning, preprocessing, K-Means Clustering & Statistical T-Test.
* **Pandas** – Data manipulation and analysis
* **Jupyter Notebook** – Data analysis
* **PostgreSQL** – Database management
* **SQL** – Business data analysis (CTEs, Window Function - DENSE_RANK, SUM OVER)
* **Power BI** – Interactive dashboard visualization

#### 📂 Project Workflow

1. **Data Collection:** Collected customer shopping behavior dataset.
2. **Data Cleaning:** Handled missing values and standardized column names using Python and Pandas.
3. **Feature Engineering:** Created additional features such as age groups and purchase frequency.
4. **SQL Analysis:** Used PostgreSQL and SQL queries to analyze customer behavior.
5. **Dashboard Development:** Created an interactive Power BI dashboard.
6. **Insights Generation:** Identified important business trends and customer patterns.

#### 📊 Dataset Information

* **Total Records:** 3,900
* **Total Attributes:** 18
* **Missing Values:** 37 in Review Rating (Handled using the median review rating of the relevant product category).

#### 📈 Key Business Insights

* Clothing is one of the strongest-performing product categories.
* Young adult customers contribute the highest revenue.
* Customers were segmented into New, Returning, and Loyal groups.
* Subscription behavior was analyzed to understand customer engagement.
* Discount usage was analyzed across different product categories.
